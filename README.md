# Nodo by Kreluna

Centralino e posto di lavoro dello studio. Orb, Clara, Lino, perle, CRM.

Repository privato: `krelunaid/nodo`.

## Avvio

```bash
npm install
npm run dev
```

Programma desktop: `npm run desktop` (con il dev server acceso) oppure `npx vite build --config vite.desktop.ts` e poi Electron.
