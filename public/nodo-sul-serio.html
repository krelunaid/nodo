Nodo by Kreluna

Quello che serve sul serio

Documento per titolare. Agosto 2026. Non è un contratto. Non è una brochure.

In una riga. Nodo è un posto di lavoro dello studio (computer + telefono +, dopo, occhiali). Tutti e tre ascoltano lo stesso centralino. Oggi hai l’interfaccia in prova. Per squillare davvero serve una linea VoIP, un account per persona, e i negozi Apple/Google solo se vuoi venderla come app da store.

1. Cosa è (e cosa non è)

È: centralino a orb, posta di gruppo, chat, perle, agenda, CRM, Clara, Lino. Marchio Kreluna. Non è YouNeed.

Non è ancora: una linea telefonica vera, un App Store, occhiali fisici, un centralino già noleggiato.

La preview è la prova. Il programma Windows è il file da aprire sul PC. L’app telefono è la stessa Nodo, faccia piccola. Gli occhiali, quando ci saranno, sono la terza faccia: una lente, non un altro programma.

3. Come suona e come riconosce (sul serio)

  1. Il cliente chiama il numero dello studio (fisso o unico).
  2. Il centralino cloud (non il PC, non l’iPhone) riceve la chiamata.
  3. Guarda le regole: interno, orario, chi è libero, se inoltrare al cellulare.
  4. Squilla i dispositivi di quella persona che in quel momento sono collegati.
  5. Rispondi da uno: gli altri smettono. «Passa a Giulia» = passa all’interno 201.

Il riconoscimento non è Bluetooth. È login + interno. Stesso account su computer, telefono, occhiali.

4. Cosa c’è già (fatto in prova)

  • Interfaccia studio: orb, foto, interni, verde/blu (interno/cellulare).
  • Passa a (foto + striscia sempre visibile).
  • Perle al posto dei post-it; Lino avvisa; Clara esegue in prova.
  • Oggi, chat, posta gruppo, agenda, CRM, moduli (fax, wiki, hotel, timbratore… in prova).
  • App tasca sul telefono (barra sotto: Oggi, Chiama, Chat, Lavoro, Altro).
  • Dispositivi: Computer / Telefono / Occhiali + specchio della lente.
  • File Windows da aprire. PDF prezzi. Repo GitHub privato krelunaid/nodo.
  • iPhone: Safari → Aggiungi a Home (senza App Store).

6. Soldi

Un abbonamento: 99 € al mese a studio, fino a 10 persone. Tutto Nodo (programma + app + aggiornamenti). Anno: 990 €.
Dall’11ª persona: +12 € / mese.
Linee (numero, minuti, SIM): a parte, all’operatore.
Licenza «l’ho comprato»: 1.490 € studio + 18% l’anno se vuole le novità. Le linee le paga lo stesso.

Senza il canone, il programma che ha sul PC resta quello. L’aggiornamento non è obbligatorio. Il noleggio include le novità.

7. Persone dello studio (da inserire voi)

Per ognuno: nome, foto, interno, cellulare, sede, se può ricevere fuori orario. La Rubrica è per i clienti, non per i colleghi.

Esempio: Chiara 200 · Giulia 201 · Marco 202. Fuori è un numero solo. Dentro il cloud smista. La segretaria smista il resto a mano.

8. Come si installa (oggi)

  • Windows 10/11: zip → Nodo.exe. Se compare l’avviso: Altre informazioni → Esegui comunque.
  • Mac: da qui non esce l’app firmata. Safari/Chrome → aggiungi al Dock. Firma Apple: sul Mac, dopo.
  • iPhone: Safari → Condividi → Aggiungi a Home.
  • Android: Chrome → Installa app / Aggiungi a Home.

Mac dal 2015 (Monterey+). Windows 10/11. Non i Mac 2012 e Windows 7.

9. Dove sta il progetto (una copia)

  • GitHub (pieno, account Kreluna): github.com/krelunaid/nodo — privato.
  • Drive «Nodo by Kreluna»: cartelle Programma / App / Documenti / Backup. Da Grok le cartelle si creano, i file zip non si caricano. Tu: GitHub → Code → Download ZIP → trascina in Programma.
  • Fissare la chat Grok tiene le parole, non il programma.

10. Ordine di lavoro (senza fare un troiaio)

  1. Tenere la prova usabile (gesti: rispondi, passa a, perle). Già in corso.
  2. Stesso login su telefono e computer (un cloud, non due copie).
  3. Collegare un centralino in osservazione / demo. Vietato il live finché non regge costi e slittamento.
  4. Poi linea vera su un interno di prova.
  5. Poi store (Apple/Google) se vuoi venderla come icona da negozio.
  6. Occhiali veri per ultimi: stessa linea, HUD già disegnato.

11. Cosa dire e cosa non dire

Dire: «È il posto di lavoro dello studio. Si affitta. Le linee le paghi a parte. Telefono e computer sono lo stesso interno.»

Non dire: «Guadagni 200 € al giorno.» «Non perdi mai.» «È YouNeed ma nostro.» «Gira su tutti i Mac vecchi.» «L’ho già messo sull’App Store.» «Gli occhiali funzionano già sul vetro.»
